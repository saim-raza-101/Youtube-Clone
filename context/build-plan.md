# Vidora Dynamic Build Plan

This is a short, changeable plan rather than a permanent roadmap.

## Current Process

1. Capture the rough idea in `context/NEXT_work.md`.
2. Inspect the relevant frontend, backend, API, model, and design context.
3. Discuss scope, UX, data behavior, edge cases, and acceptance criteria.
4. Move the finalized idea into a feature prompt under `context/features/`.
5. Before coding, update this file with the feature name and a short implementation outline.
6. Implement only the approved scope.
7. Validate affected behavior and update `progress-tracker.md`, `ui-registry.md`, and related documentation.

## Active Feature

No feature is currently finalized. The next feature will be selected from `NEXT_work.md` after discussion.

## Plan Format

For the active feature keep only:

- Goal
- Affected areas/files
- UI and behavior steps
- Data/API impact
- Validation commands
- Rollback or safety notes
