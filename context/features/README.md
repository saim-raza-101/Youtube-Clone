# Finalized Feature Prompts

Store one reviewed implementation prompt per feature in this folder.

## Naming

Use a concise lowercase name ending in `_feature.md`, for example:

```text
login_feature.md
creator_analytics_feature.md
video_recommendations_feature.md
```

## Required Sections

- Feature goal and user value
- Finalized scope and explicit non-goals
- Existing behavior and files inspected
- Frontend changes
- Backend/API/database changes, if any
- UX states and responsive/accessibility requirements
- Acceptance criteria
- Validation commands and manual checks
- Safe rollout or rollback notes

The prompt is a reviewed execution contract. AI implementation must not begin until the user has reviewed and approved it.
